# Семейный архив Штыковых

Статический сайт на HTML, CSS и JavaScript. Сборка и серверная база данных не нужны. Семейные тексты, фотографии, видео и проект дома сохранены из исходного сайта.

## Запуск

Из корня репозитория:

```sh
python -m http.server 4173
```

Откройте `http://localhost:4173`. Используйте HTTP-сервер: карта загружает локальный JSON через `fetch`, поэтому открытие `index.html` через `file://` не подходит для проверки карты.

Для публикации на GitHub Pages достаточно файлов из корня репозитория. Относительные пути работают и в подпапке `/shtykovfamily/`. Публикация обновлений происходит только после переноса изменений в ветку, выбранную в настройках хостинга.

## Содержание и обновление

- `index.html` — страницы, родственные связи в SVG, письма и история семьи.
- `styles.css` — общая палитра, типографика, адаптивная вёрстка.
- `app.js` — навигация, поиск, карта, диалоги, фотоальбомы, черновики.
- `data.js` — места путешествий и карточки родственников. `current: true` отмечает Москву как текущее местоположение, перенесённое из исходного сайта; автоматической геолокации нет.
- `photos/` — оригинальные семейные материалы. Указывайте в `data.js` только существующие файлы, учитывая регистр букв в имени. Если фотографий нет, оставьте `photos: []`.
- `assets/viktor-poster.jpg` — кадр из существующего видео Виктора для обложки и его карточки.
- `assets/vendor/`, `assets/world.json` — локальные зависимости карты и география мира. Источники и лицензии перечислены в `assets/THIRD_PARTY.md`.

Разделы доступны по ссылкам `#home`, `#family`, `#travels`, `#history`, `#anniversary`. Старые обозначения `#tree`, `#ai`, `#hobbies` поддерживаются.

Форма воспоминаний сохраняет один черновик **только в localStorage текущего браузера** и скачивает UTF-8 текстовый файл. Она не отправляет данные, не добавляет родственников в общую базу и не публикует истории. Для добавления нового рассказа в общий архив нужно обновить содержимое сайта. Ограничение явно указано рядом с формой.

Видеопоздравление загружается с YouTube только после нажатия кнопки. Его доступность зависит от YouTube и доступа к оригинальному ролику; рядом есть прямая ссылка. Остальные страницы, семейные фото и карта не используют внешние CDN.

## Проверки

Нужен Node.js. Установите только инструменты разработки и браузер:

```sh
npm install
npx playwright install chromium
```

Запустите HTTP-сервер на порту 4173 в отдельном терминале, затем:

```sh
npm test
```

`SITE_URL` позволяет указать другой адрес, `BROWSER_CHANNEL=chrome` — использовать установленный Chrome. `CAPTURE_DIR` сохраняет скриншоты страниц при функциональной проверке. Тесты проверяют навигацию, существование фото, фильтры, диалоги, клавиатуру, локальные черновики и скачивание, ошибки карты и хранилища, мобильное меню, отсутствие горизонтального переполнения. Проверка axe охватывает страницы и открытые диалоги; автоматический аудит не заменяет ручную проверку доступности.

В исходном репозитории есть одинаковые файлы `photos/victor.MP4` и `photos/victor.mp4`, а также `photos/nnvo3.jpg` и `photos/nnov3.jpg`. Они сохранены; сайт использует имена в нижнем регистре `victor.mp4` и `nnov3.jpg`.
